About this voting system
Your ballot is encrypted
It is encrypted in your browser before it is sent.
Every ballot is recorded
Each accepted ballot is written to a log that anyone can check.
Your receipt proves it counted
It shows your ballot exists. It never shows how you voted.
Results can be checked
The published total can be recomputed from the log.
Administrators: first run needs the one-time code printed in the server terminal.
